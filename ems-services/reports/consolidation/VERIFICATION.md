## Environment recovery and limits

Cloud-offloaded source and generated caches stalled reads. Matching committed files were recovered from Git; original placeholders, draft scaffolding and old generated outputs were preserved under ignored .local directories. Frontend dependencies were reinstalled from npm's cache. The old Docker registry metadata lookup stalled, so local validation used a tagged existing trusted Java 17 runtime image via EMS_RUNTIME_IMAGE; the default clean Dockerfile still uses Temurin 17. Docker and local port binding require host tool permission in this desktop environment.

Attendance score measures whether completed published shifts have any overlapping non-rejected attendance. Partial presence counts as present; it does not measure lateness, breaks or complete-shift coverage. Payroll remains current-rate gross-pay estimates; finalized payroll, taxes and paid-leave pay remain deferred. No hosted deployment or AWS capacity certification is claimed. CI was updated but its remote execution is not claimed.
